# Ren Yamaguchi (山口 蓮)

Systems and distributed infrastructure engineer based in Tokyo, Japan.

Working on low-latency systems, kernel I/O (`io_uring`, epoll), zero-copy serialization, and asynchronous runtime concurrency. Most of my work revolves around deterministic state machines, memory efficiency, and robust data pipelines under high concurrency.

### Areas of Focus
- **Low-Latency Runtimes**: Async I/O architectures, event loops, and lock-free thread synchronization.
- **Zero-Copy Protocols**: High-throughput queues, compact binary serialization, and cache-aligned memory layouts.
- **Distributed State**: Consensus protocols, transaction semantics, and deterministic fault-injection testing.

### Stack
- **Languages**: Rust, C++, Go, Python
- **Ecosystem**: Tokio, Linux tracing, gRPC, Protobuf, RocksDB, Redis
